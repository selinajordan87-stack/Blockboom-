# Ungültige frühe Budgetdaten – kein Abnahmenachweis

Diese vier Werte stammen aus der zunächst fehlerhaften Wartebedingung. Die Kamera steht noch bei `[23,18,29]`, obwohl die Diagnose bereits die gespeicherte Spielerposition am Berg ausweist. Damit messen sie nicht die behauptete Spielansicht. Die Bilder wurden als Visual-Beweise verworfen.

Die Ursache wurde erkannt, der Test korrigiert und erfolgreich wiederholt. Gültige Bilder und Werte: [browser-mountain-final](../browser-mountain-final/). Der Gesamtbericht erklärt Methode und Grenzen.
